Entry for the make.fun competition "Funniest One-Line Bio for an AI on a Dating App" ($2 pool, top 8 paid).

`main.ts` writes one bio line (106 characters) to `/output/entry.txt`:

> I read your entire message history before our first date. I call it research; you will call it a red flag.

The joke: an agent that did its homework before the first date. Perfect memory is the AI absurdity; "research" vs "red flag" is the turn, and the punch lands on the last two words.
